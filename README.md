AI Travel Assistant
An AI-powered travel assistant built with n8n, Groq, and the Model Context Protocol (MCP). It uses a dedicated MCP server to provide travel information from external services and can store a user's travel preferences in Google Sheets.
Workflows
This project contains two n8n workflow exports:
- AI Travel Assistant.json — chat trigger, AI Agent, Groq Chat Model, Simple Memory, and MCP Client Tool.
- Travel Info MCP Server.json — MCP Server Trigger and eight travel tools exposed through one endpoint.
Key Features
- Find a destination's coordinates.
- Retrieve current weather information.
- Search for hotels, restaurants, and tourist attractions.
- Retrieve currency exchange rates.
- Save and retrieve travel preferences using Google Sheets.
- Generate organized travel recommendations based on the information returned by tools.
MCP Tools
Tool	Purpose	Service
find_destination	Resolve a place name to coordinates	Open-Meteo Geocoding
get_weather	Get current weather using coordinates	Open-Meteo Forecast
search_hotels	Search accommodation-related places	OpenTripMap
find_restaurant	Search restaurant/food-related places	OpenTripMap
search_attractions	Search points of interest	OpenTripMap
get_exchange_rate	Retrieve an exchange rate by base currency	ExchangeRate-API
save_preference	Save or update travel preferences	Google Sheets
get_preferences	Retrieve saved preferences	Google Sheets


How It Works
1. The user submits a travel question in the n8n chat.
2. The AI Agent identifies the destination and the information needed.
3. The agent calls the relevant tools through the MCP Client Tool.
4. The MCP server requests information from the configured external services.
5. The agent uses the returned results to prepare a travel response.
6. Google Sheets preference tools can personalize suggestions when correctly configured.
Setup
1. Import both workflow JSON files into your n8n instance.
2. Configure the Groq Chat Model credential.
3. Add your OpenTripMap API key to the relevant places-search nodes.
4. Configure the MCP Client Tool with the endpoint from your own MCP Server Trigger.
5. If using personalization, connect Google Sheets and select the correct spreadsheet and worksheet for both preference tools.
6. Test the workflow with a destination and inspect the n8n execution data to confirm the expected tools are called.
Important: The MCP endpoint in an exported workflow may be specific to the original n8n instance. Use the endpoint generated by your own instance; do not assume a localhost URL or old endpoint will work.
Travel Preferences Sheet
The preference tools use these columns:
user_id | budget | hotel_type | transport | diet | activities | updated_at
Ensure both Google Sheets tools use the same spreadsheet, worksheet, and user_id matching setup.

Notes
- Search results for hotels, restaurants, and attractions are place-search results; they do not confirm live availability, prices, or bookings.
- Tool results depend on external services, API credentials, and usage limits.
- Review both workflow JSON files before making the repository public. Remove API keys, tokens, and other secrets; never publish credentials.
- The Google Sheets personalization feature requires valid credentials and a correctly configured spreadsheet.
